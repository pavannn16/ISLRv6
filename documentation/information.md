## About SignEase

SignEase is an application that uses computer vision and machine learning to detect and interpret sign language in real-time. The application aims to bridge communication gaps between the deaf/hard-of-hearing community and those who don't understand sign language.

Key features include:
- Real-time sign language detection
- Sign language dictionary
- AI visualization of sign language processing
- Text-to-speech conversion of detected signs
