Accessing Camera on HTTP Sites from Different Devices
When accessing your application from another device using HTTP (not HTTPS), you'll encounter camera permission issues because modern browsers block camera access on non-secure connections. Here are two solutions to this problem:

Solution 1: Enable Insecure Camera Access in Chrome (Temporary Testing Only)
For temporary testing purposes only, you can configure Chrome on the client machine to allow camera access on insecure origins:

On the Windows machine, open Chrome and navigate to:
chrome://flags/#unsafely-treat-insecure-origin-as-secure
Find the setting "Insecure origins treated as secure"

Enter your application's URL in the text field:
http://192.168.0.101:3000
Change the dropdown from "Disabled" to "Enabled"

Click "Relaunch" to restart Chrome

When you visit the site again, you should be able to grant camera permissions

# Commands for specific Node.js and Next.js versions
# Ensure you are using a compatible Node.js version (e.g., 16.x or 18.x) and Next.js version 14.x

# Install Node.js on macOS
brew install node@16
brew link --overwrite node@16

# Install Node.js on Linux

# For Node.js 16 (deprecated)
curl -fsSL https://deb.nodesource.com/setup_16.x | sudo -E bash -
sudo apt-get install -y nodejs

# For Node.js 20 LTS (recommended)
# First uninstall existing Node.js
sudo apt-get remove -y nodejs nodejs-doc
sudo apt-get purge -y nodejs
sudo apt-get autoremove -y

# Then install Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verify installation
node --version

# Install Next.js globally (optional, for development convenience)
npm install -g next@14
